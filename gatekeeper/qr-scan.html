If the camera will not start
  • Open the portal as http://localhost:3000/gatekeeper/qr-scan.html. Browsers block cameras on plain IP addresses and on file:// pages.
  • Allow camera access when the browser asks. If you blocked it earlier, click the padlock in the address bar and reset the camera permission.
  • Close any other app using the webcam (Zoom, Teams, Meet, the Camera app).
  • Still stuck? Use Scan from Photo or type the token — both verify exactly the same way.
